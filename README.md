# To-Do List App

A simple and interactive **To-Do List application** built using HTML, CSS, and JavaScript. It allows users to add tasks, mark them as completed, and delete tasks. Tasks are saved in the browser's Local Storage, so they remain available after refreshing the page.

## Features

- **Add Tasks:** Enter a task and press Enter to add it to your list.
- **Mark as Completed:** Click the check icon to mark a task as completed or undo it.
- **Delete Tasks:** Remove tasks you no longer need using the trash icon.
- **Local Storage:** Automatically saves tasks and their completion status in your browser.
- **Simple Interface:** Clean and easy-to-use design.

## Technologies Used

- **HTML5** – Structures the application.
- **CSS3** – Styles the user interface.
- **JavaScript** – Handles task creation, completion, deletion, and storage.
- **Font Awesome** – Provides check and trash icons.
- **Local Storage** – Stores tasks in the browser.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.

## How to Use

1. Type your task into the input field.
2. Press **Enter** to add the task.
3. Click the check icon to mark the task as completed.
4. Click the trash icon to delete the task.
5. Refresh the page to see your saved tasks.
